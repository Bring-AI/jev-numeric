02 / BEHIND THE ACTIONS

A number made
of choices.

JevNeo subdivides a numeric range, asks Jev which interval to keep, and refines it until one grid cell remains.

Read the algorithm ↗
A

Branching ≠ resolution

K is the number of choices at a refinement step. Resolution is the final grid spacing. A larger K changes the tree’s depth, not the requested precision.

B

Telemetry in. Controls out.

The controller receives structured state information. Numeric outputs drive the game’s continuous action space on a finite grid. The model does not receive the rendered gameplay.

C

No training. Inspectable attempts.

These are inference-time control experiments with no model training. Each game’s run ledger includes recorded unsuccessful attempts, settings, timing, and available media.
